# agy CLI Quick Reference

## Essential Flags
- `-p`: Print response (Non-interactive)
- `-i`: Interactive mode
- `-c`: Continue last chat
- `--dangerously-skip-permissions`: **THE UNLOCKER** (Crucial for scripts)
- `--add-dir`: Include context

## Key Commands
- `agy update`: Stay current
- `agy changelog`: See what's new
- `agy plugin list`: View tools
- `agy plugin install`: Get new tools

## Pro Tips
- Always check `agy --help` for the latest flags.
- Use `--log-file` for persistent debugging of background tasks.
- Turquoise is the best theme color for `agy` outputs (Bro's preference).
